À propos

Toolbox est une boîte à outils web personnelle : convertir, calculer, analyser, sans pub, sans compte à créer ailleurs, sans données revendues. Elle tourne sur un petit serveur Oracle Cloud gratuit, avec des logiciels libres uniquement.

Ce que fait ce site

  • Outils texte & code : compteur, Base64, hash, JSON, mots de passe…
  • Calculatrices : scientifique, TVA, unités, moyennes…
  • Bioinfo : GC%, transcription, traduction, FASTA…
  • Images : conversion, resize, QR codes…
  • Documents PDF : fusion, extraction, rotation, métadonnées…
  • Média : conversion MP4 → MP3.

Tout est exécuté sur le serveur, en local : aucun fichier n'est envoyé à un service tiers. Login privé, rate limit anti brute-force, HTTPS.
